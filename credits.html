Third-party licences — MC Parrot

Last updated: 29 September 2026
Short version: MC Parrot's own code is written by its author and is proprietary (see the licence). It ships together with a few components made by other people, listed here. Those components stay under their own licences, and their authors have our thanks.

In every version (web, Android, Windows)

MP3 encoder — lamejs

  • What it does: it writes the file when you export a song as MP3. Nothing else uses it.
  • Package: @breezystack/lamejs 1.2.7, a maintained build of lamejs, the JavaScript port of the LAME encoder (lame.sourceforge.net).
  • Licence: GNU Lesser General Public License, version 3. Full texts: LGPL 3.0 and GPL 3.0.
  • Source code: github.com/shijinyu/lamejs.
  • How it is shipped: as a separate file, lame.js, byte for byte the file the package publishes (dist/lamejs.iife.js). It is not modified, not merged into our code and not obfuscated. MC Parrot loads it only when an MP3 export starts, and talks to it through its public interface (lamejs.Mp3Encoder).
  • You can replace it: build your own version of the library as a script that defines a global lamejs object with the same interface, and put it in place of lame.js. On the web it sits next to index.html. On Windows it is inside the application archive (resources/app.asar, folder app). On Android it is inside the package (assets/public/lame.js).

FFT — fft.js

  • What it does: the Fourier transform used to analyse the sounds you record.
  • Package: fft.js 4.0.4, Copyright Fedor Indutny, 2017.
  • Licence: MIT. Full text: MIT licence of fft.js.
  • Source code: github.com/indutny/fft.js.

What is not here

No sound library, no sample pack, no loop and no model ships with MC Parrot. Every sound in a song comes from what you recorded or from the files you opened.
